# 📦 NonFiscal ERP — Sistema de ERP Web com Ponto de Venda

Este é um **ERP Web Não Fiscal**, desenvolvido em **PHP + MySQL**, com funcionalidades de controle interno, operações administrativas e módulo de **Ponto de Venda (PDV)** integrado.  
Inclui geração de relatórios em **PDF via DOMPDF**, sistema de autenticação, páginas dinâmicas e estrutura simples para implantação rápida.

---

## 🧠 Tecnologias Utilizadas

- **PHP 7+**
- **MySQL / MariaDB**
- **DOMPDF** – geração de PDF's
- **HTML / CSS / JavaScript**
- **Bootstrap** (se presente nas páginas)
- **Sessões PHP** para autenticação
